# 芽谱 V2.3 六册全景知识图谱重构报告

日期：2026-08-28

## 结论

六册 Full Graph 的默认布局已从“固定教材坐标 + 六簇扇形”改为构建期 ForceAtlas2 全局知识网络。浏览器继续使用 V2.2 的按需 Canvas 2D 渲染，不引入运行时力模拟，因此保留全量研究数据与交互能力，同时避免持续占用 CPU。

默认知识网络只使用规范知识实体和真实知识关系参与受力计算；教材节点与 Provenance 关系默认隐藏，不再把图拉回六个教材中心。原教材簇布局完整保留为第二视图，新增 Schema 分组视图。

## Neo4j NVL 技术 Spike

评估版本：`@neo4j-nvl/base@1.2.1`、`@neo4j-nvl/react@1.2.1`

- React `InteractiveNvlWrapper` 与 `layout="forceDirected"` 可以通过当前 Vinext 静态构建。
- 安装后新增 72 个包。
- Spike 路由生成约 1,761,457 B 主客户端 chunk。
- 另生成约 513,548 B Cose-Bilkent Worker 与 151,586 B Hierarchical Worker。
- 这些运行时代码会显著高于当前 Full Graph 单 Canvas 的前端成本，并引入运行时布局生命周期。

因此采用需求允许的后备方案：Graphology + ForceAtlas2 在构建期预计算，运行时不携带 NVL。Graphology 仅作为开发/构建依赖，不进入页面客户端 bundle。

## 三视图

1. 知识网络 / Knowledge Network：默认；全局 ForceAtlas2 规范知识网络。
2. 教材分簇 / Textbook Clusters：保留原六册教材簇，观察册次分布。
3. 知识模式 / Schema：按实体语义类型组织全部规范实体，观察模式结构。

## 视觉编码与交互

- 节点大小由 degree、textbookCount、occurrenceCount、relationCount 综合得到的 visualImportance 决定。
- Fit 远景只候选 Top 35 标签，并进行标签碰撞避让；放大后逐级扩展到 Top 100、Top 300 和全部可视节点。
- 普通知识关系浅灰；跨册关系较明显；Provenance 为虚线且默认隐藏。
- 选择节点后显示 1-hop 强高亮、2-hop 次级高亮，其余节点与关系降低透明度。
- 保留点击、双击展开、右键菜单、节点拖拽、背景平移、滚轮缩放、Fit、重置、Mini Map、搜索、筛选、Inspector 与 Evidence。
- Full Graph 的 1-hop / 2-hop 仍只做集合高亮，不复制节点或关系。
